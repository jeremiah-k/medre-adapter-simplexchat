# Scoped native SimpleX replies

Advertise native replies through the existing destination/profile-bound quote
path. Missing or unavailable retained parents keep readable fallback; accepted
handoffs reuse their native reference and uncertain handoffs remain fenced.
Threads remain fallback. No configuration or frozen schema changes are required.

The peer campaign is supplemented by timestamped restart/fault traces, actual
native send counts and independent bounded recipient observation. Queue
acceptance is not recipient delivery; source, SDK and scope remain explicit.
